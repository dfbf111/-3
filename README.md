# ARCHI Portfolio

React + Vite personal portfolio for ARCHI / 练亚奇.

## Run

```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.

## Notes

- Home uses a local Three.js model with interactive project, about, and contact hotspots.
- Projects include a scrolling archive and detail galleries using local assets in `public/assets/`.
- About and Contact include portrait / WeChat lightbox previews.
